I keep coming back to one question: how does complex behavior emerge from simple rules? 
What I'm working on

Collective motion in living tissue. Extending the Vicsek model with viscous and Maxwell viscoelastic terms to explain cell movement during axolotl epiboly, fit against experimental explant data (with Dr. Holley Lynch). Along the way I built an analysis tool for microscopy images and lab data that we now use for soft matter research, plus a Streamlit app for exploring the model interactively.
Chaos-based random number generation. Co-authored a hybrid RNG built on chaotic dynamics, validated against the NIST SP 800-22 test suite with quantified entropy metrics. Manuscript currently under journal review.
Order flow in limit order books. Feature engineering pipeline for Order Flow Imbalance on high-frequency LOB data, the groundwork for short-horizon price prediction.
Phase transitions in AI systems. Exploring whether ideas from statistical physics (critical points, order parameters, sudden qualitative shifts) can help describe and anticipate failures in AI models.

Before this

Software engineering intern at Lena, where I worked on a Flutter app and Django backend that delivers course materials to students in low-connectivity regions. It's deployed and in use today.
